# 灵感市集 · UI 原型

一个移动端优先的点子交易产品高保真原型。产品不卖一句脑洞，而卖包含证据等级、执行成本、行动步骤与清晰授权的“点子说明书”。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器支持通过 `--host` 和 `--port` 指定监听地址。

## 已实现流程

- 首页浏览、关键词搜索、分类筛选与空结果恢复
- 点子详情、免费预览、收藏与授权说明
- 明确标注的模拟购买、完整正文解锁和示例附件下载
- 三步发布、字段校验、草稿本机保存与模拟发布结果
- 企业悬赏大厅、分类与排序、模拟投标及投标状态保存
- 企业悬赏发布与实时分账计算器：中标 70%、有效投标激励池 10%、平台服务费 10%、待分配 10%
- 点子购买分账明细：创作者 70%、共创激励池 10%、平台服务费 10%、待分配 10%
- 个人中心的已购、收藏、发布和显示偏好
- 移动端底部导航、桌面侧边导航、键盘焦点与弹窗 Esc 关闭

## 原型边界

所有点子和企业悬赏均为虚构演示数据。支付、发布、投标和资金托管仅模拟界面交互，不连接后端或真实支付；收藏、购买状态、投标记录与草稿仅保存在当前浏览器 localStorage 中。附件按钮下载的是用于演示的文本示例，不是真实商业材料。
